## Evidence handling

- A statement in a provided document is `Reported` until confirmed through the responsible owner or authoritative system.
- Repository, hosting, IAM, cost, and security claims require technical verification.
- Source dates must be retained because the application estate may change quickly.
- Sensitive source material should be stored only in an approved location with appropriate access controls. The files stored here are kept in a private repository; remove them if Capital Factory asks, or if the repository's access ever widens.
